1. `git branch --show-current`, `git status -sb`로 로컬 수정사항 확인.
2. 백업·비교 후 ZIP의 `D.Part` 네 파일을 프로젝트의 `D.Part`에 복사.
3. `git diff -- D.Part/01-gtfs-input-requirements.md D.Part/02-api-response-format.md` 확인.
