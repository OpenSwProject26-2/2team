# C · 대체 버스 노선 및 차량 배분

## 어떤 역할인가요?

버스 파업으로 노선이 중단됐을 때, 한정된 대체 버스를
**어떤 노선에 몇 대씩 배치해야 더 많은 승객을 시간 안에 수송할 수 있는지**
계산하고 비교하는 파트입니다.

예를 들어 버스 8대를 여러 노선에 골고루 배치하는 방법과
수요가 많은 노선에 집중하는 방법을 비교해 더 나은 운행안을 찾습니다.

## 처리 흐름

교통망·이동 수요·차량 조건 입력
→ 운행 가능한 후보 노선 확인
→ 노선별 차량 배분 변경
→ 수송 가능한 인원과 대기시간 추정
→ 좋은 운행안을 B 파트에 전달

## 주요 기능

- **기준안 생성:** 기존 노선에 차량을 균등 배분하거나 수요에 비례해 배분합니다.
- **후보 노선 검사:** 노선의 방향·연결·회차·복귀 조건을 확인합니다.
- **근사 평가:** 정원과 시간 제한을 고려해 수송 가능한 인원을 빠르게 추정합니다.
- **배분 탐색:** 차량을 다른 노선으로 옮기며 더 좋은 배분안을 찾습니다.
- **소규모 전수 비교:** 가능한 배분을 모두 계산한 결과와 탐색 결과를 비교합니다.

운행안은 **시간 내 도착하는 인원이 많은 순서**로 평가합니다.
충족 인원이 같으면 대기시간과 운행거리를 비교합니다.

## 다른 파트와의 연결

| 파트 | 주고받는 내용 |
| --- | --- |
| A · 데이터 | 교통망, 기존 노선, 시간대별 이동 수요를 받습니다. |
| B · 시뮬레이션 | 선택한 노선과 차량 배분을 전달하고, 상세 평가 결과를 받습니다. |
| D · 서비스 | 운행안과 비교 결과가 운영자 화면에 표시되도록 연계합니다. |

C는 노선과 차량 배분을 결정합니다.
차량별 실제 출발표 생성과 상세 시뮬레이션·독립 검증은 B가 담당합니다.

## 현재 구현 범위

- 작은 합성 데이터와 고정 후보 노선 3개
- 균등·수요 비례 기준안
- 구간별 정원과 수요 중복을 고려한 근사 평가
- 탐욕 배분·차량 이동 탐색
- 전수 비교와 B 평가 연동 인터페이스

실제 데이터 연결, 후보 노선 자동 생성, 실제 B 시뮬레이터 연동은 후속 작업입니다.

현재 결과는 **가정한 조건에서 계산한 추정치**입니다.
실제 운행 승인이나 현장 성능을 의미하지 않으며,
탐색 결과가 모든 가능한 운행안 중 최적임을 보장하지 않습니다.
