# D 운영자 지도 관측 시간: 07:30~09:00

운영자 지도의 관측 버스 수요원은 `07:30~09:00` 구간을 표시한다. 현재 공유 자료 `share_k5/seoul/YYYYMMDD/stop_route_hourly.csv`에는 시간별 `H=07`, `H=08` 합계만 있다. 따라서 표시값은 **07시 승하차량의 50% + 08시 승하차량의 100%**로 계산한 추정치다. 이는 07:00~07:30과 07:30~08:00의 실제 승객 분포가 같다는 가정이다.

파업·운행 제외 노선의 영향 승차와 지하철 관측 API에도 동일한 시간 가중치를 적용한다. 지하철 관측 인원은 지도 버스 수요원에 합치지 않는다. API 요청은 `hour=morning_0730_estimate`를 사용하며, 응답의 `time_window`는 `07:30~09:00`, `time_window_status`는 `hourly_half_hour_estimate`다. 기존 `hour=morning`은 07:00~09:00의 시간별 합계로 유지한다.

이 값은 정확한 30분 관측량이나 미충족 수요가 아니다. 모든 관측일에서 정확히 집계하려면 정류장·노선별 승하차 시각이 들어 있는 비식별 원자료 또는 30분 단위 집계가 필요하다. 현재 공유 파일은 시간별 집계만 제공한다. 원시 교통카드 자료와 카드 식별자는 저장소에 넣지 않는다.
