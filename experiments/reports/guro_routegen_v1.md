# 구로구 후보 노선 생성 + 구 단독 배분 v1 — 국소 탐색 수정·N_max·R 민감도

실험 데이터(10/26~30) 5일 묶음 결과다. 이 문서의 숫자는 모두 `experiments/guro_routegen/make_report_v1.py`가 결과 파일(`manifest.json`, `candidates/*.json`, `runs.json`, 실행별 `metrics.json`·`timetable.json`)에서 계산했다. 보고서를 손으로 고치지 않고 스크립트를 고친다.

## 요약

- 실행 260회(조건 10개 · 안 52개 × 5일) 중 변환기·M05·M07 pass **260회**. 후보 주기 C = 시뮬레이터 `period_s` 1525/1525건.
- **국소 탐색 수정(1-1)**: 노선 교체·2~3대 옮기기·초기해 3개(탐욕·수요 상위·피더안 배분)를 넣었다. 우리 안 근사 ≥ 같은 설정 피더안 근사: 26/26안. 기본 조건에서 시뮬레이터 충족률이 피더안보다 높은 조건 2/8, 두 안이 같은 조건 6/8.
- 기본 조건 우리 안 충족률 v0 대비 변화: +0.00%p ~ +0.94%p (8조건 평균 +0.28%p).
- **민감도(affected 18안)**: 우리 안 충족률(11·13대 평균)이 가장 높은 조건은 N_max 8 · R 3km(13.64%)이고 나머지 8개는 -0.71%p 이하로 낮다. v1 기본값으로 기본값 유지를 제안한다(§7).
- **정차 수 상한은 삽입을 막는 유일한 원인이 아니었다.** R 3km·N_max 8에서 삽입 거절 6,753회 중 정차 수 **하나만** 걸린 것은 168회다. 나머지는 편도·우회율에도 함께 걸린다. 그래서 N_max를 12나 제한 없음으로 풀어도 삽입 통과율은 7.1%–8.2%에 머문다. R 3km에서는 N_max를 풀면 충족률이 오히려 내려간다. 확인한 원인 하나는 피더 후보 규칙(수요 상위 seed 중 제약을 지키는 처음 15개)이다. 긴 피더가 들어오며 짧은 피더가 밀려나, 기본값 우리 안 노선 중 N_max 12 후보에 없는 것 1/7개, N_max 제한 없음 후보에 없는 것 1/7개가 된다(§5).
- **R을 줄이면 O 포화는 풀리지만 충족률은 내려간다.** O 중앙값 R 3km 1.47 → 2km 0.40 → 1.5km 0.04. 그래도 τ 0.2에서는 군집이 상한 3을 넘어 실제 쓰인 τ의 최솟값이 1.5km 0.25, 2km 0.85, 3km 1.85이다. 권역이 줄면 후보가 덮는 수요가 줄어, R별 최고 조건의 충족률이 R 3km 최고보다 2km -0.81%p, 1.5km -3.19%p다(§5·§7).
- 편도 연결 seed 5,322회 중 통과 4회. 거절의 62.0%는 편도·정차 수·우회율 셋에 동시에 걸렸다. 제약 하나만 걸린 거절은 망에서 못 닿음 648회, 우회율 1.6 36회, 정차 수 N_max 8회뿐이다(§6).
- 구로구 지자체안: 전사본이 미병합 브랜치에 있으나 그대로는 변환기를 통과하지 못해 매트릭스에 올리지 않았다(§8).

## 2. v0 → v1에서 바뀐 것

**알고리즘(기본 조건에도 적용)**

- 국소 탐색: 매 회차 `1대·2대·3대 옮기기`(주는 노선은 1대 이상 남김)와 `노선 교체`(열린 노선 하나를 닫고 안 열린 후보를 n0 = ⌈C/1200⌉대로 연다. 모자라면 다른 노선에서 1대씩 — 뺄 때 근사 손실이 가장 작은 노선부터, 1대는 남김 — 가져오고 남으면 이득 큰 노선에 1대씩)를 모두 평가해 가장 좋은 개선 하나를 받는다. 개선이 없을 때만 v0의 `닫고 재배분`을 시도한다.
- 초기해 3개: 탐욕(CELF) + 남는 대수 채우기, 수요 상위 노선부터 n0씩, 같은 설정 피더안의 최종 배분. 각각 국소 탐색 후 근사 최대를 고른다(동률이면 이 순서). 피더안 배분은 우리 풀의 같은 정차열 후보로 옮겨 넣는다. 피더 풀 정차열이 우리 풀에 없으면 그 후보를 우리 풀에 더한다(이번 실행에서 더한 후보 수: base 0, N8_R1500 0, N8_R2000 0, N8_R3000 0, N12_R1500 0, N12_R2000 0, N12_R3000 0, Nnone_R1500 0, Nnone_R2000 0, Nnone_R3000 1).
- 우리 안 근사 < 피더안 근사이면 생성기가 멈춘다. 단위 테스트 `test_result_not_below_feeder_plan`(임의 사례 24개)과 `test_feeder_start_lifts_stuck_case`(탐욕·수요 상위 초기해만으로는 피더안보다 낮아지는 사례)가 이것을 확인한다.
- 피더안도 같은 배분기(초기해: 탐욕·수요 상위)로 다시 배분했으므로 v0 피더안과 대수가 다를 수 있다.
- 거절 사유 진단: 최단경로를 못 잇거나 정류장이 겹쳐 v0에서 `no_path_or_repeat` 하나로 묶이던 판정을, 상한 없는 최단경로로 이어 붙인 정차열에 제약을 모두 매겨 제약별로 센다(결과 후보에는 영향 없음 — v0와 기본 조건의 후보·삽입 시도 수가 같다). 단계 이름에 L_max를 붙였다(`seed_L20`, `insertion_L30` …).

**파라미터**

- 기본 조건(`base`)은 v0 기본값 그대로다: τ 0.2, τ_step 0.05, 군집 상한 3, R 3km, F_min 540, L_max 20·30분, N_max 8, 우회율 1.6, 섹터 2·3·4, 피더 seed 상위 15, Jaccard 0.8.
- 민감도(`sens/N{N}_R{R}`, affected만)는 지시대로 N_max ∈ {8, 12, 제한 없음} × R ∈ {1.5, 2, 3}km만 바꿨다. τ 0.2·군집 상한 3을 포함한 나머지는 기본값이다. 결과를 보고 다른 파라미터를 바꾼 것은 없다.
