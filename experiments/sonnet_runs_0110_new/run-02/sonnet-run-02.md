- R-1801: 개봉 일대 → 개봉역(1호선) 환승 / 2대 / 수요가 가장 큰 권역이고 1호선으로 서울역·종각·시청 직결이 가능해 2대 배분.
- R-1802: 오류동 일대 → 오류동역(1호선) 환승 / 2대 / 두 번째로 큰 미접근 수요권, 1호선 직결.
- R-1701: 구로 일대 → 구로역(1호선) 환승 / 2대 / 수요가 크고 1호선·환승 접근성이 좋음.
- R-1821: 온수 일대 → 온수역(1호선) 환승 / 1대 / 서쪽 외곽 수요, 1호선·7호선 연결.
- R-2751: 천왕 일대 → 천왕역(7호선) 환승 / 1대 / 가산·남구로 등 7호선 목적지 수요 대응.
- R-2747: 남구로 일대 → 남구로역(7호선) 환승 / 1대 / 7호선 목적지(가산디지털단지 등) 수요 대응.
- R-0233: 대림 일대 → 대림역(2호선) 환승 / 1대 / 2호선 목적지(강남·역삼 등) 수요 대응.
- R-0234: 신도림 일대 → 신도림역(1·2호선) 환승 / 1대 / 환승 거점, 2호선 수요 대응.

## 충분히 서비스하지 못한 수요
- 구로디지털단지(0232), 가산디지털단지(1702/2748) 권역은 별도 노선이 없고 인근 노선(대림·남구로)에 흡수됨. 구디 권역 수요는 낮은 편으로 판단.
- 노선당 상위 수요 정류장 7~9곳만 포함해 소수요 정류장은 방문하지 못함. 정류장당 수요가 작은 권역은 도착률이 낮을 수 있음.
- 11대로는 2시간 총 수송 용량이 수요(16,230명)에 크게 못 미쳐 만차 대기·20분 초과 이탈이 불가피함.
- rail_known=0 인 829명은 도착 인정이 안 되므로 서비스 대상에서 제외하지 않았으나 구제할 방법이 없음.

## 가정한 값
- 정류장→철도역 연결은 정류장과 역의 거리가 가장 가까운 access.csv 정류장(허브 정류장)을 각 노선의 종점으로 가정. 하차 후 도보 500m 이내.
- 정류장 간 이동은 직선거리 기준으로 순서를 정했고 실제 도로·속도는 모름.
- 철도 노선·환승·소요시간 자료가 없어 호선 구성(1·2·7호선 직결)은 역 ID 접두와 상식에 의존함.
- 각 정류장은 직선거리가 가장 가까운 허브 정류장에 배정했고, 허브 정류장 2.5km 이내·수요 상위 순으로 선택함.
