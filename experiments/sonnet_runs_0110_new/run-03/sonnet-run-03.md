## 충분히 서비스하지 못한 수요·권역
- 차량이 11대뿐이라 노선당 1대이며, 노선 외 저수요 정류장(전체 473곳 중 다수)과 신도림·구로디지털단지·대림 권역은 직접 서비스하지 못함. 1대 순환 시 배차 간격이 길어 20분 대기 한도를 넘는 승객이 많을 것.
- rail_known=0인 829명은 도착으로 인정되지 않으므로 노선 설계에서 제외함.
## 판단 이유
- 11대를 노선당 1대로 균등 배분: 수요 가중 k-평균으로 11개 권역을 나누어 각 권역 최상위 수요 정류장 최대 8곳을 한 노선으로 묶음(차량 수와 노선 수가 같음). 짧은 노선으로 회전율을 높임.
## 가정
- 철도 소요시간·환승 데이터가 없어 역 간 철도 시간은 평가하지 않았고, 셔틀 속도·정차 시간도 가정 없이 거리 기준으로만 노선 길이(허브 2.2km 이내)를 제한함.
- 승객은 환승역에서 목적지로 철도 이용이 가능하다고 가정함(성능은 평가자 시뮬레이터에 맡김).
