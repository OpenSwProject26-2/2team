# sonnet-run-06 운행안 (차량 11대)

## 노선별 요약

- R01: 신도림동·구로역 일대 → 구로역(1호선) 환승 / 1대 / 구로 권역 수요가 많고 정류장 간격이 짧아 회차가 빠름.
- R02: 구로변전소·구로초 일대 → 구로역(1호선) 환승 / 2대 / 구로 권역 중 수요가 가장 두터운 묶음이라 2대 배치.
- R03: 구로4동(고대구로병원) 일대 → 남구로역(7호선) 환승 / 1대 / 남구로 권역 수요가 크고 하차 정류장이 역 출구 바로 옆.
- R04: 우신중고 일대 → 온수역(1·7호선) 환승 / 2대 / 온수 권역 수요 대비 짧은 거리, 두 노선 환승 가능.
- R05: 개봉1동사거리(호반써밋개봉) 일대 → 오류동역(1호선) 환승 / 2대 / 수요 최대 밀집지가 오류동역에서 약 0.8km라 짧은 회차로 많이 태울 수 있음.
- R06: 천왕이펜하우스5단지 → 천왕역(7호선) 환승 / 1대 / 천왕 권역 수요가 한곳에 몰려 있음.
- R07: 대원주유소 일대 → 개봉역(1호선) 환승 / 1대 / 개봉 권역 서쪽 수요를 개봉역으로 연결.
- R08: 고척중 일대 → 개봉역(1호선) 환승 / 1대 / 개봉 권역 동쪽 수요, 하차 정류장이 역에서 약 50m.

배분 합계: 1+2+1+2+2+1+1+1 = 11대, 노선 8개.

## 두 목표 사이의 선택 (한 줄)

90분 내 도착 인원을 우선해 차량을 가장 수요가 몰린 곳에 두고, 평균 누적 수요충족률(빠른 도착)은 노선을 0.4~0.8km의 한 번 정차 짧은 순환으로 만들어 회차와 승차 시간을 줄이는 방식으로 함께 챙겼으며, 대신 먼 지역은 포기하고 수송 가능 인원이 많은 곳에 집중했다.

## 충분히 서비스하지 못한 수요·권역

- 차량 11대×45인승으로는 2시간 총수요 16,230명 중 일부만 수송 가능하다. 용량이 가장 큰 제약이다.
- 노선의 승차 정류장 500m 안에 들어가지 못하는 권역이 있다: 역곡(약 816명), 구로디지털단지(약 329명), 온수(2752 기준 약 286명), 신도림(약 275명 중 대부분), 양천구청(약 651명 중 대부분). 이 권역들의 도착률은 매우 낮거나 0%일 수 있으며, 최저 도착률 권역 지표에는 불리하다.
- 오류동 권역(약 2,566명)은 R05 한 노선으로 일부만 포괄한다. 구일·온수 권역도 일부만 포괄한다.
- `rail_known=0` 829명은 설계 대상이 아니며 도착으로 인정되지 않는다.

## 판단 이유

- 판단은 CSV 수요(`people` 합계)와 정류장·역 좌표로 계산했다. 승차 정류장 반경 500m 안의 수요를 노선별 포괄 수요로 보고, 노선당 회차시간으로 수송 가능 인원을 추정해 대수를 배분했다.
- 노선 후보는 하차 정류장이 역에서 150m 이내인 곳으로 제한했다.
- 같은 수요 밀집지를 R05, R07, R08이 일부 공유한다. 한 노선이 독점하는 것보다 두 하차 역으로 나누는 편이 대기 한도 안에서 더 많이 태운다고 판단했다.

## 자료에 없어 가정한 값

- 셔틀 평균 속도 약 20km/h, 직선거리 대비 도로 1.3배, 정차당 약 2분, 회차 3분.
- 수요는 07~09시 2시간에 균등하게 도착한다고 보고, 승차 정류장 반경 500m 안 수요의 약 85%가 이용 가능하다고 가정했다.
- 철도 이동시간과 환승 구조는 자료에 없어 계산에 반영하지 않았고, 하차역은 인접 노선 수와 노선 연결성을 기준으로 상식적으로 골랐다.
- 공식 도착률과 평균 누적 수요충족률은 평가자가 계산하며 이 문서에서 추정하지 않았다.
