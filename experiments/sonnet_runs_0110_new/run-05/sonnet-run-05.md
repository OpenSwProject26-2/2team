## 두 목표 사이의 선택
90분 내 도착 인원을 우선해 대수를 수요 많고 노선이 긴 권역(개봉·오류동·온수)에 더 주고, 노선을 짧게 유지해 회전을 빠르게 하여 평균 누적 수요충족률에도 도움이 되도록 했다.

## 충분히 서비스하지 못한 수요
- `rail_known=0` 829명은 도착으로 인정되지 않아 제외했다.
- 신도림·구로디지털단지·도림천·광명사거리 권역과 역 500m 안 정류장 수요는 걸어서 갈 수 있다고 보고 노선을 두지 않았다. 차량이 11대뿐이라 노선당 상위 수요 정류장 일부(권역 수요의 약 60~90%)만 방문하며, 나머지와 먼 정류장 수요는 미서비스일 가능성이 크다.
- 정확한 권역별 도착률은 계산하지 않았고 공식 점수는 추측하지 않는다.
