# sonnet-run-08 운행안 (차량 11대 전부 배분, 노선 11개)

## 노선별 요약 (출발 지역 → 환승시킬 철도역 / 차량 대수 / 선택 이유)

- R01 구로4동·구로시장 일대 → 남구로(7호선) / 1대 / 고대구로병원 앞 인접 정류장 3곳에 수요가 몰려 있어 짧은 순환으로 묶음.
- R02 고척시장·고척중 → 개봉(1호선) / 1대 / 고척시장 단일 정류장 수요(298명)가 커서 2정류장 단거리로 회전율 확보.
- R03 오류고·수궁119 → 온수 / 1대 / 정류장당 수요가 큰 서부 외곽(336·185명)을 온수역으로 직결.
- R04 구로변전소·한국SGI → 신도림(1·2호선) / 1대 / 환승 폭이 넓은 신도림으로 보내 철도 이동 시간 이점을 노림.
- R05 개봉1동사거리·세곡초 → 개봉 / 1대 / 두 정류장 수요가 각각 250명대로 높고 거리가 짧음.
- R06 개봉한진아파트·개봉중앙시장 → 개봉 / 1대 / 기점 정류장(280명)을 포함해 개봉역 방면 대형 수요 흡수.
- R07 구로구청·구로보건소 일대 → 대림(2호선) / 1대 / 구로구청 주변 분산 수요를 2호선 환승이 가능한 대림으로 연결.
- R08 고척파크푸르지오·덕의초 → 구로(1호선) / 1대 / 아파트 단지 수요(203·144명)를 구로역으로 연결.
- R09 개봉푸르지오·고척근린공원 → 개봉 / 1대 / 인접한 3개 정류장 수요를 짧은 경로로 묶음.
- R10 디지털단지오거리·삼부르네상스 → 구로디지털단지(2호선) / 1대 / 역과 가까운 구간이라 이동이 짧아 조기 도착에 유리.
- R11 궁동·우신중고·온수힐스테이트 → 온수 / 1대 / 궁동·온수동 외곽의 대형 정류장(189·155명)을 온수역으로 연결.

## 두 목표 사이의 선택 (한 줄)

차량당 수송량이 용량 한계라 정류장당 수요가 크고 역까지 짧은 구간(2~5정류장, 약 0.6~1.7km)을 우선해 90분 내 도착 인원을 늘리는 쪽에 두되, 구간이 짧아 조기 도착도 함께 얻도록 하고 철도 연결이 넓은 신도림·구로디지털단지·대림·구로 방면을 일부 섞었다.

## 충분히 서비스하지 못한 수요·권역

- 전체 rail_known=1 수요 15,401명 중 노선이 지나는 정류장의 수요 합은 5,024명이다(정류장 단위 사실이며 도착 인원이 아니다). 나머지 정류장, 특히 천왕·구일·오류동 방면과 남쪽 외곽은 서비스하지 못한다.
- rail_known=0 829명은 분모에 남고 도착으로 인정되지 않는다.
- 11대 × 45석으로는 두 시간 수요를 다 싣기 어렵고 배차 간격이 길어 20분 대기 한도를 넘는 승객이 생길 수 있다. 서비스 못 하는 권역의 도착률은 낮을 것으로 예상하며, 형평성은 확보하지 못했다.
- 500m 안에 역이 있는 정류장 승객은 셔틀 없이 도보로 역에 갈 수 있다고 보고 노선에서 제외했다.

## 판단 이유와 가정한 값

- 가정: 셔틀 평균 속도 20km/h, 정류장당 정차 30초, 종점 회차 5분. 철도 시간표·환승 정보는 자료에 없어 역의 노선 수(허브성)로만 우선순위를 줬다.
- 일부 정류장 이름이 같지만 ID가 달라 별개 정류장으로 취급했다. 연속 중복 ID는 없다.
- 공식 점수와 순위는 추측하지 않는다. 평가자 계산을 따른다.
