# sonnet-run-04 운행안

## 노선별 요약
- R1-구일: 고척동·개봉동·구로동 일대(고척시장~신도림동.구로역) → 구일역 환승 / 3대 / 수요가 가장 밀집한 8개 정류장(약 2,000명)을 연결하고 대수를 가장 많이 배분.
- R2-오류동: 천왕·개봉·오류동 일대(천왕이펜하우스5단지~오류동역) → 오류동역 환승 / 2대 / 서남부 외곽의 수요 집중 정류장과 1호선 오류동역 연결.
- R3-대림: 구로4동·신도림·구로디지털단지 일대(구로디지털단지역~구로고등학교) → 대림역 환승 / 2대 / 2호선 환승 거점으로 강남·종각 방면 목적지 접근에 유리.
- R4-개봉: 고척·개봉1동·오류1동 일대(덕의초~개봉역.림괄아파트) → 개봉역 환승 / 2대 / 개봉역 주변 고수요 정류장 연결.
- R5-남구로: 구로1동·디지털단지오거리 일대(구로보건소~남구로역2번출구) → 남구로역 환승 / 2대 / 7호선 접근이 가능하고 노선 길이가 짧음.

## 충분히 서비스하지 못한 수요
- 473개 정류장 중 약 40개만 5개 노선에 포함했다. 나머지 정류장의 수요는 미수송으로 남는다. 천왕·온수·광명사거리·가산디지털단지·도림천·신도림 외곽 권역 등이 해당한다.
- rail_known=0인 829명은 분모에 남고 도착으로 인정되지 않는다.
- 노선당 1~3대로 45인승 용량이 작아, 포함된 정류장 중에서도 만차로 20분 대기 한도를 넘는 승객이 생길 수 있다.

## 판단 이유
- 차량 11대로는 전체 수요(16,230명)를 수송할 수 없다고 판단했다(대당 2시간 약 130명 수준으로 추정). 그래서 노선 수를 5개로 줄이고 노선당 2대 이상을 배치해, 배차간격을 대기 한도 20분 이내로 맞추려 했다.
- 수요 상위 정류장을 철도역 500m 이내 종점 정류장과 묶고, 노선을 짧게 유지해 90분 안에 도착할 확률을 높였다.
- 권역 형평성은 일부 포기했다. 수요가 낮고 흩어진 권역은 도착률이 낮을 것으로 보이며, 용량이 한정된 상황에서 총 도착 인원 극대화를 우선했다.

## 가정한 값
- 정류장 간 도로 이동은 직선거리 기반으로 어림했고, 평균 차속·정차 시간은 자료에 없어 가정했다.
- 목적지별 철도 소요시간은 자료에 없어 직접 계산하지 않았다. 환승역은 2호선·1호선·7호선 접근성과 수요 위치를 기준으로 판단했다.
- 개별 출발 시각은 평가자가 정한다.
