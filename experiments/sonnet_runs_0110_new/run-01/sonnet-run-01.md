# sonnet-run-01 운행안

## 노선별 요약 (출발 지역 → 환승시킬 철도역 / 차량 대수 / 선택 이유)
- R-온수: 천왕·항동 등 서쪽 끝 → 온수역(1·7호선) / 1대 / 가장 서쪽 외곽 수요를 한 번에 모아 1호선·7호선으로 연결.
- R-오류동: 천왕·오류동 일대 → 오류동역(1호선) / 2대 / 근처 정류장 수요가 크고 도보권 철도역이 없는 정류장이 많음.
- R-개봉: 개봉·고척 일대 → 구일역(1호선, 종점 정류장 기준) / 3대 / 개봉·구일 권역 수요가 가장 커서 최다 배분.
- R-구로: 구로동 일대 → 구로역(1호선) / 2대 / 수요 상위 권역이며 서울역·시청 방면 1호선 직결.
- R-신도림: 신도림·도림천 일대 → 신도림역(1·2호선) / 1대 / 정류장이 적어 짧은 노선, 환승 편의 최고.
- R-대림: 구로시장·남구로 일대 → 남구로역(7호선, 종점 정류장 기준) / 2대 / 대림·구디·남구로 수요를 7호선(가산디지털단지 등 상위 목적지 방면)으로 연결.

## 충분히 서비스하지 못한 수요·권역
- rail_known=0 인 829명은 구조적으로 도착 불가.
- 노선당 정류장을 최대 14개로 제한해 각 권역 하위 수요 정류장은 제외함. 권역별 수요 합 대비 노선 포함 수요는 온수 약 1,783/2,605, 오류동 2,250/3,756, 개봉 2,250/4,142, 구로 1,279/2,049, 대림 1,723/2,936, 신도림 658/742. 개봉·오류동 권역이 가장 많이 누락됨.
- 가산디지털단지·광명사거리 권역은 전용 노선이 없고 대림 노선으로 일부 흡수.

## 판단 이유
- 11대 전부 배분. 권역별 수요 비례 + 환승 가능 철도역 접근성을 기준으로 단순 배분했고 시뮬레이션은 하지 않음.
- 정류장은 수요 상위 순으로 선택 후 먼 곳에서 역 쪽으로 최근접 이웃 방식으로 순서화, 종점은 철도역 500m 이내 정류장.

## 가정한 값
- 정류장 간 속도, 정차 시간, 도보 속도, 철도 이동시간 등은 자료에 없어 가정하지 않고 평가자 값에 맡김.
- 권역·거리는 위경도 직선거리로 근사(위도 111km, 경도 88km/도).
- 종점 정류장에서 도보 가능한 역(access.csv 기준)만 환승 역으로 간주.
