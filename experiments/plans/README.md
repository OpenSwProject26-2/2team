# 운행안 원본 보존

비교에 쓰는 운행안의 **원본**과 **출처**를 여기에 둔다. 규칙은
`docs/design/evaluation-protocol.md` §4를 따른다.

## 왜 출처를 분리하는가

프로토콜 C5가 *"시간표 생성기·엔진·검증기·지표 계산기는 어느 안인지 읽지 않는다"* 로 정한다.
그래서 **`plan.json`에는 출처가 들어가지 않는다.** `plan_id`도 `plan-01`처럼 출처를 드러내지
않는 이름을 쓴다. 어느 안이 어디서 왔는지는 `manifest.json`에만 있다.

이름에 `muni`·`gpt` 같은 단어를 넣지 않는다. 파일 이름만 봐도 출처를 알면 분리한 의미가 없다.

## 구조

```text
experiments/plans/
├─ README.md            이 파일
├─ schema.md            변환 규칙
├─ manifest.json        plan_id → 출처 (비교 실행에는 쓰지 않는다)
└─ plan-01/
   ├─ plan.json         비교 입력. 출처 정보 없음
   ├─ conversion.md     원본 → plan.json 변환 기록과 해석 지점
   └─ source/           원본 보존
      ├─ ...
```

## `manifest.json`

```json
{
  "fixed_at": "2026-11-__",
  "plans": {
    "plan-01": {"origin": "municipal", "collected_at": "2026-11-__", "url": "..."},
    "plan-02": {"origin": "llm", "model": "...", "version": "...",
                "called_at": "2026-11-__", "sample": 1, "of": 3},
    "plan-06": {"origin": "ours", "code_commit": "...", "config": "..."}
  }
}
```

`origin` 값은 `municipal` / `llm` / `ours` 셋만 쓴다. 분석할 때만 읽는다.

## `source/` 에 넣는 것

| 출처 | 보존할 것 |
| --- | --- |
| 지자체안 | 출처 URL, 수집일, **비교에 쓴 집계만**(노선·정류장열·대수). 원문 전체를 복제하지 않는다 |
| 범용 AI안 | 프롬프트 전문, 모델에 준 입력, **모델 출력 원문 그대로**, 모델명·버전·호출일·설정 |
| 우리 알고리즘안 | 생성에 쓴 코드 커밋과 입력 설정 |

표본을 n개 뽑았으면 **n개 전부** 보존한다. 형식이 깨져 변환하지 못한 출력도 남기고
`conversion.md`에 사유를 적는다. 조용히 버리지 않는다(프로토콜 §4.2).

## 저장소에 넣지 않는 것

- 원시 교통카드 자료, 개인 이동 내역, 인증키
- 저작권·이용 조건을 확인하지 못한 원문 전체
- 용량이 큰 원본 파일 — 출처 URL과 수집일, 재취득 방법만 남긴다

## 지금 상태

**비어 있다.** 아직 어떤 운행안도 수집·실행하지 않았다. 자료를 넣기 전에
`docs/design/evaluation-protocol.md` §5.1(지표 정의 통합)과 §8의 미정 항목을 먼저 정해야 한다.
