# 구로구 파업 대체 셔틀 운행안

| 노선 | 출발 지역 → 철도 환승역 | 배분 | 선택 이유 |
| --- | --- | ---: | --- |
| R01 | 롯데아파트 → 구로역 | 1대 | 아파트 인근 수요를 짧은 회차로 태우고 구로역1번출구에서 먼저 내릴 수 있게 했다. |
| R02 | 고척동 청구·동아한신아파트 → 구일역 | 1대 | 공동주택 밀집 구간을 동양미래대학·구로성심병원 정류장 한 곳에 연결해 회차를 짧게 유지한다. |
| R03 | 굴다리·호반써밋개봉아파트 → 오류동역 | 1대 | 굴다리 주변의 밀집 수요를 오류1동주민센터 정류장으로 직송해 좌석을 자주 공급한다. |
| R04 | 구로4동우체국·고대구로병원 → 남구로역 | 1대 | 병원과 구로4동 일대의 수요를 구로시장 정류장으로 짧게 연결한다. |
| R05 | 두암빌라·럭비구장 → 온수역(1821·2752) | 1대 | 두 승차 지점을 두고, 럭비구장과 온수역 정류장에서 목적지에 맞는 두 철도 노선으로 갈 수 있게 했다. |
| R06 | 현대2차아파트 일대 → 개봉역 | 1대 | 아파트 쪽 수요를 모아 역까지 CSV상 도보 131초인 중간 하차 지점과 도보 155초인 종점을 연결한다. |
| R07 | 구로중학교·구로구민회관 → 대림역(0233·2746) | 1대 | 두 생활권을 대림역4번출구에 연결해 목적지에 맞춰 철도 노선을 선택하게 했다. |
| R08 | 개봉소공원·호반써밋개봉아파트 → 오류동역 | 1대 | R03과 겹치는 승차권의 좌석을 보강하고, 소공원 쪽과 오류1동주민센터의 두 정류장을 잇는다. |
| R09 | 개봉한진아파트 → 광명사거리역 | 1대 | 개봉 남부의 아파트 수요를 모아 개명초교 정류장에서 철도로 이어 준다. |
| R10 | 구일초·구일고·구일중학교 일대 → 구일역 | 1대 | 고척동의 R02와 별도로 구로1동 주거지를 구일역에 연결한다. |
| R11 | 연지타운2단지·오남중학교 → 천왕역 | 1대 | 천왕권 승차 지점을 두 곳으로 넓히고 도보 77초인 천왕역2번출구에서 환승시킨다. |

- **두 지표 사이의 선택**　자체 비교에서 신도림행 대안이 0~90분 평균 누적 수요충족률에 더 유리했지만, 90분 이내 도착 인원을 더 확보한 천왕행을 배정했다.
- **승차 접근권의 한계**　출발 정류장에서 노선의 승차 지점까지 직선 500m를 적용하면 4,483명(철도망 포함 4,217명)이 접근권 밖에 있다. 최근접역 기준 역곡(816명), 구로디지털단지(329명), 신도림(275명), 가산디지털단지(2748, 243명), 도림천(183명) 권역은 승차 접근권이 없다. 온수(2752)는 286명 중 4명, 양천구청은 651명 중 120명이 접근권에 든다. 접근 가능 비중이 10% 미만인 위 6개 권역의 수요는 2,132명이다. 역곡·온수(2752)권의 항동 일대와 양천구청권 북부까지 연결하는 후보는 회차가 길어졌고, 동쪽의 별도 지선보다 기존 밀집 승차권의 좌석과 천왕·개봉 남부 연결을 우선했다.
- **대기와 미도착**　짧은 회차로 10분 내 승차 기회를 늘리되, 45석이 차면 다음 차량을 기다리다가 최대 대기 20분을 넘길 수 있다. 철도망 밖 수요 829명도 전체 16,230명에 포함했다.
- **비교에 쓴 가정**　직선거리 기준 승차 전 보행속도는 1.25m/s, 셔틀 유효속도는 약 13~17km/h로 두고 정차 24초와 회차 105~170초를 더했다. 하차 후 도보는 access.csv 값을 사용했고, 철도 시간은 역 ID·좌표·동명역 환승을 바탕으로 근사했다. 시간대별 수요는 균등 출발과 시간대 경계에 더 몰리는 출발을 비교했다. 실제 도로 회차와 철도 배차는 입력 자료에서 확인할 수 없다.
