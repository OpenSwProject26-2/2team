# 구로구 대체 셔틀 운행안 · sol-run-07

- **R01** 개봉1동 호반써밋 앞(굴다리) → 오류동역(오류1동주민센터·오류문화센터 하차) / 1대 / 개봉1동사거리와 호반써밋 일대의 집중 수요를 짧은 직결편으로 받는다.
- **R02** 동부골든아파트·오류동교회 → 오류동역(오류동역 정류장 하차) / 1대 / 두 주거지에서 한 번씩 승차한 뒤 오류동역으로 연결해 R01과 승차권을 나눈다.
- **R03** 개봉사거리 → 개봉역(개봉역 정류장 하차) / 1대 / 개봉사거리에서 한 번에 연결하고, 하차 정류장에서 역까지의 보행을 131초로 줄인다.
- **R04** 개봉3동 개웅어린이공원 → 개봉역(개봉역 정류장 하차) / 1대 / 광명사거리역이 가장 가까운 개봉3동 수요에도 개봉역 연결을 제공한다.
- **R05** 고척시장 일대(유풍약국) → 구일역(동양미래대학·구로성심병원 하차) / 1대 / 시장 주변 수요를 한 승차점에 모아 중간 정차 없이 구일역 도보권으로 보낸다.
- **R06** 구로1동주민센터·하이츠/영화/우방/한국현대아파트 → 구일역(1호선구일역 정류장 하차) / 1대 / 구로1동 아파트 두 지점에서 승차해 구일역으로 이어지는 별도 연결을 둔다.
- **R07** 롯데아파트·신도림동 구로역 일대 → 구로역(구로역·NC신구로점 하차) / 1대 / 신도림동·구로역 정류장 주변의 집중 수요를 롯데아파트에서 받아 짧게 연결한다.
- **R08** 구로구청후문 → 대림역(구로고등학교 하차) / 1대 / 구청 주변 수요에 짧은 직결편을 두고, 하차 후 도보 153초인 대림역 연결을 쓴다.
- **R09** 구로시장·남구로역6번출구 → 남구로역(2번출구 정류장 하차) / 1대 / 구로시장과 고대구로병원 주변에서 승차할 수 있게 하고 역까지 도보 150초인 곳에 내린다.
- **R10** 궁동·온수힐스테이트 일대(두암빌라) → 온수역(1821·2752, 온수역 정류장 하차) / 1대 / 우신중고와 힐스테이트 주변을 한 승차점에서 받고 두 역 ID 모두에 짧은 보행으로 연결한다.
- **R11** 천왕이펜하우스 5·6단지(5단지 승차) → 천왕역(3단지입구 하차) / 1대 / 5·6단지 수요를 모아 짧게 운행하고 3단지입구에서 역까지 도보 165초 연결을 쓴다.

**두 목표 사이의 선택** · 90분 내 도착 인원을 우선해 11개 직결 노선에 1대씩 배분했고, 도착 인원이 비슷한 후보에서는 회차와 환승 보행을 줄여 0~90분 누적 수요충족을 앞당기는 쪽을 골랐다.

## 남는 수요와 권역

- 마지막 정류장을 철도 환승용 하차점으로 두었을 때, 앞선 승차점까지 직선 500m를 넘는 수요는 4,757명이다. 가장 가까운 역으로 권역을 나누면 역곡(816명), 온수 2752 권역(286명), 구로디지털단지(329명), 가산디지털단지 2748 권역(243명), 도림천(183명)은 승차권에 닿지 않는다.
- 역곡역에는 CSV에 등록된 하차 연결이 없고, 항동·푸른수목원까지 온수 노선을 늘리면 왕복이 길어져 궁동 쪽 좌석 공급이 줄어든다. 양천구청 권역은 651명 중 528명, 신도림 권역은 275명 중 255명이 승차권 밖에 남는다. 이 권역들과 동남권에도 전담 차량을 두는 안을 비교했으나, 11대는 도착 인원 확보에 유리한 단거리 연결에 배분했다.
- 500m 승차권 안에서도 07시대에 수요가 몰리면 만차와 대기가 생길 수 있다. 철도망에 포함되지 않은 829명은 전체 수요 16,230명에 포함했다.

## 비교에 둔 가정

정류장 사이 도로 거리는 직선의 1.20~1.30배, 셔틀 속도는 시속 17~24km, 정차는 22~32초, 기점 복귀 후 회차 여유는 85~110초로 놓았다. 승차 전 보행은 초속 1.15~1.27m로, 하차 후 역까지의 보행은 CSV의 시간으로 계산했다. 철도는 역 간 직선거리 1km당 135~170초에 대기·환승 부담 10~13분을 더해 비교했다. 시간대 안에서 출발이 고른 경우와 앞쪽에 몰리는 경우를 함께 보았으며, 실제 도로·철도 시간과 배차에 따른 성적은 평가에서 결정된다.
