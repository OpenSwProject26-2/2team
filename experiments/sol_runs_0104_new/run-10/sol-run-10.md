- **S01** 수궁동 두암빌라·학교 밀집지 → 온수역 / 1대 / 두암빌라 승차권에 수궁동의 학교·주거지 수요를 모아 중간 정차 없이 연결한다.
- **S02** 항동하버라인·푸른수목원 → 온수역(럭비구장 하차) / 1대 / 철도 도보 접근이 부족한 항동에서 환승 지점까지 중간 정차 없이 연결한다.
- **S03** 금강수목원아파트·연지타운 → 천왕역 / 1대 / 연지타운에 정차해 천왕이펜하우스 남쪽까지 승차 범위를 넓히고 2번 출구로 연결한다.
- **S04** 개봉중앙시장·개봉3동 → 개봉역(현대2차APT 하차) / 1대 / 시장 주변과 개봉한진아파트 일대의 수요를 두 승차 정류장으로 모은다.
- **S05** 개봉1동사거리·거성푸르뫼아파트 → 오류동역(오류1동주민센터 하차) / 1대 / 개봉1동사거리와 주변 아파트의 집중 수요를 중간 정차 없이 연결한다.
- **S06** 용두연립·성화단지 → 개봉역(개봉사거리 하차) / 1대 / 세곡초등학교와 고척근린공원 방면의 승차권을 두 정류장으로 확보한다.
- **S07** 마젤란아파트·예인학원앞 → 구일역(동양미래대학·구로성심병원 하차) / 1대 / 덕의초·고척시장·고척중 방향 수요가 겹치는 정류장에서 바로 연결한다.
- **S08** 구일우성아파트·구로1동주민센터 → 구일역 / 1대 / 구일 남쪽 주거지의 수요를 두 정류장에서 태워 역 앞에 내려 준다.
- **S09** 구로도서관·구로구청 → 대림역(구로고등학교 하차) / 1대 / 거리공원과 구청 주변 수요를 나눠 태우고 대림역으로 이어지는 도보 구간을 짧게 유지한다.
- **S10** 고대구로병원 후문·정문 → 남구로역(구로시장 하차) / 1대 / 구로119안전센터·병원 일대의 밀집 수요를 모아 시장 쪽에서 철도로 연결한다.
- **S11** 지하이시티·디지털단지오거리 → 남구로역 / 1대 / 디지털단지오거리와 가리봉 일대의 철도 접근 공백을 줄인다.

**두 시간 지표의 절충** 개봉 남부는 중앙시장 정차를 포함해 90분 내 도착 가능한 출발지를 넓히고, 온수 북부는 중간 정차 없이 연결해 대기·이동을 줄이는 쪽을 택해 0~90분 평균 누적 수요충족률도 고려했다.

## 서비스가 부족한 곳

- 역곡이 가장 가까운 권역의 항동 서쪽(우남퍼스트빌·구로SKV1), 오류동 권역의 오류중학교·삼원목욕탕, 양천구청 권역의 고척고교 주변은 승차 정류장 500m 범위 밖에 남는다. 이곳까지 경유하면 회차가 늘어나므로 수요가 겹치는 승차 지점에 차량을 배분했다.
- 구로역 권역의 신도림 서쪽 일부에도 승차권 공백이 남는다. 별도 배차는 철도 도보 연결이 드문 항동·고척·개봉 등과 07시대 밀집 수요에 우선 사용했다. 항동·천왕 등 07시대 집중 구간은 45석과 최대 대기 20분 제약 때문에 만차 후 일부 수요가 남을 수 있다.
- 철도망 미포함(rail_known=0) 829명은 전체 수요 16,230명에 포함된다.

## 비교에 쓴 가정

07시·08시 각 시간대의 출발을 그 시간 안에 고르게 배치했다. 도보 4.5km/h, 셔틀 도로거리 직선의 1.23배, 주행 18~27km/h, 정차 약 24초와 종점 복귀를 가정했다. 철도 이동은 역 간 직선거리의 1.35배와 21~31km/h, 일괄 8분 여유로 비교했다. 역 도보 연결은 access.csv의 도보 시간을 적용했다.
