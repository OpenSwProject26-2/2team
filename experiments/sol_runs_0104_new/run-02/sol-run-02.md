# 구로구 버스 파업 대체 셔틀 · sol 2회차

## 운행안

- **R01** 신도림 동아2차아파트 일대 → 구로역 / 1대 / 신도림과 도림천 쪽 주거지 수요를 짧은 구간으로 구로역에 연결한다.
- **R02** 개봉1동 굴다리·호반써밋 일대 → 오류동역 / 2대 / 승차지 반경 500m에 수요가 집중돼 있어 45석 만차에 따른 대기를 줄이도록 2대를 배분했다.
- **R03** 현대아파트·개봉중앙시장 일대 → 개봉역 / 1대 / 개봉 남쪽 주거지에서 승객을 태우고, 개봉역까지 도보 155초인 정류장에서 내려준다.
- **R04** 고척 청구아파트·동아한신아파트 일대 → 구일역 / 2대 / 승차지 주변의 구일·개봉 권역 수요를 함께 받으며, 수요 집중에 대응해 2대를 배분했다.
- **R05** 항동 푸른수목원 후문 일대 → 온수역 / 1대 / 역곡·온수 권역에 걸친 항동 수요를 모아 온수역의 두 역 ID(`1821`, `2752`)에 연결한다.
- **R06** 거리공원 일대 → 대림역 / 1대 / 구로·대림 권역 경계의 주거지 수요를 모아 대림역까지 도보 153초인 구로고등학교 정류장에 내려준다.
- **R07** 지밸리비즈플라자·하이엔드1차 일대 → 남구로역 / 1대 / 승차 지점을 두 곳 두어 구로디지털단지와 가산디지털단지 쪽 수요를 함께 받는다.
- **R08** 궁동입구 일대 → 오류동역 / 1대 / 궁동입구 주변에서 온수·오류동·천왕 권역에 걸친 수요를 모아 오류동역에 연결한다.
- **R09** 남구로역 6번 출구 주변 주거지 → 대림역 / 1대 / 남구로 북쪽 수요를 모아 영서중학교에서 내려 대림역으로 이어지게 한다.

## 남는 수요와 계산 가정

- 출발 정류장을 직선거리상 가장 가까운 역 ID로 나눴다. 천왕 권역은 1,008명 중 850명, 온수(`1821`) 권역은 1,301명 중 814명이 선정한 승차 정류장 반경 500m 밖이다. 천왕의 아파트 단지 안쪽까지 경유하는 대신 궁동입구 한 곳에서 일부만 받는다. 온수는 수목원 후문과 궁동입구 두 승차권에 집중해 그 밖의 주거지 접근이 제한된다. 구로 권역도 1,983명 중 901명이 반경 밖이다. 반경 안에서도 출근 피크에는 만차로 20분 내 승차하지 못하는 수요가 생길 수 있다. 철도망 미포함 829명은 전체 16,230명에 포함했다.
- `people`로 시간대별 수요를 합산하고, 45석 공급과 대기 20분 한도 아래 90분 내 도착 가능성을 근사해 노선을 골랐다. 10분 내 승차 가능성과 수요 100명 이상 권역의 서비스 공백도 함께 고려했다.
- 시간대 안의 출발은 균등하게 분포한다고 가정했다. 승차 전 보행은 직선거리의 1.2배를 시속 4.5km로, 셔틀 거리는 직선거리의 1.35배를 시속 17km로 계산했다. 정류장 간 이동에 정차 30초, 복귀에 회차 여유 3분을 반영하고 최소 순환시간을 8분으로 뒀다. 하차 후 보행은 `access.csv`의 초 값을 썼다. 철도는 역 간 직선거리의 1.25배를 시속 24km로 계산하고 대기·환승 12분을 더했다. 동일·인접 역(350m 미만)은 철도 구간에 2분을 적용했다.
