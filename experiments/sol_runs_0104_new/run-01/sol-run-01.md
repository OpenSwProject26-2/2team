# 구로구 버스 파업 대체 셔틀 운영안

- **R01** 항동 하버라인·푸른수목원 → 온수역 / 1대 / 역곡역에 가까운 항동 주거지에 온수역 환승 경로를 마련한다. 동진빌라·오정초등학교에서 내려 온수역까지 걷는다.
- **R02** 두암빌라·우신중고 일대 → 온수역 / 1대 / 예림디자인고와 수궁119안전센터 주변의 수요를 한 승차점에 모으고 온수역 정류장에서 내려 환승 보행을 줄인다.
- **R03** 연지마을·천왕이펜하우스 → 천왕역 / 1대 / 연지마을에서 이펜하우스 여러 단지의 수요를 받는다. 3단지입구 하차 후 역까지 도보 연결은 444m다.
- **R04** 오류1동주민센터·동부골든아파트 일대 → 오류동역 / 1대 / 오류문화센터 주변에 모인 수요를 짧은 구간으로 실어 나르고 오류동역 2번출구에서 내린다.
- **R05** 고척시장·덕의초등학교 일대 → 개봉역 / 1대 / 경남아파트앞에서 고척 북부 수요를 모으고 개봉사거리에서 내려 철도로 잇는다. 양천구청역이 가장 가까운 권역의 일부도 이 노선을 이용할 수 있다.
- **R06** 개봉3동·한진아파트 일대 → 개봉역 / 1대 / 경북슈퍼마켓에서 한진아파트·대원주유소 주변 수요를 받고 현대2차APT에서 내려 철도로 잇는다.
- **R07** 고척중학교·공구상가 일대 → 개봉역 / 1대 / 고척 중부 수요를 공구상가에서 모아 개봉역·한마을아파트 정류장까지 짧게 운행한다.
- **R08** 솔길공원·고대구로병원 정문 일대 → 남구로역 / 1대 / 병원 정문과 구일우성아파트 주변의 수요를 받아 구로시장에서 내려 남구로역으로 잇는다.
- **R09** 구로변전소·구로구청 일대 → 구로역 / 1대 / 구로초등학교와 구로119안전센터 주변 수요를 짧은 회차로 처리한다. 구로2동성당에서 내려 구로역으로 걷는다.
- **R10** 신도림중학교·신도림동 일대 → 신도림역 / 1대 / 신도림중학교에서 주거지 수요를 모아 동아2차아파트상가에서 내려 신도림역 두 철도 노선으로 연결한다.
- **R11** 지밸리비즈플라자·디지털단지오거리 일대 → 남구로역 / 1대 / 지밸리비즈플라자와 하이엔드1차 두 곳에서 승객을 모아 구로남초등학교에서 내려 남구로역으로 잇는다.

## 서비스가 부족한 수요와 권역

- 각 노선의 마지막 정류장을 환승 하차점으로, 그 이전 정류장을 승차점으로 놓으면 어느 승차점에도 직선 500m 안에 닿지 않는 출발 수요가 5,304명이다. 오류동 권역의 세곡초등학교·개봉푸르지오 일대 등 1,557명, 구일 권역의 동양미래대학·구로성심병원 일대 등 901명이 여기에 포함된다. 항동 노선을 배정했어도 역곡 권역의 항동우남퍼스트빌 일대 등 223명은 승차점에서 500m를 넘는다. 신정네거리 권역은 29명 전원이 승차점 범위 밖이다.
- 승차점에 닿아도 07시대 집중 수요로 만차가 반복될 수 있다. 항동과 고척 북부 노선은 회차가 길어 10분 이내 탑승에 특히 불리하다. 철도망에 없는 목적지로 향하는 829명은 전체 16,230명에 포함된다.

## 비교에 사용한 가정

정류장 간 도로 거리는 직선거리의 1.40배, 셔틀 주행 속도는 시속 18km로 놓았다. 중간 정차에 30초, 양 끝 정차와 회차에 합계 3.1분을 더했다. 승차 전에는 시속 4.3km로 걷는다고 보고, 하차 후에는 CSV의 도보 시간을 사용했다. 철도 이동에는 역 간 직선거리의 1.35배와 시속 27km를 적용하고 승차 대기·환승 부담으로 8분을 더했다. 후보 비교에서는 시간대 안에 수요가 분산된다고 보고 회차당 45석 기준 공급량의 94%를 유효 좌석으로 잡았다. 90분 안에 도착할 가능성, 10분 이내 탑승 가능성, 서비스가 부족한 권역의 수요를 함께 비교했다.
