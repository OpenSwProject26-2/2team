# 구로구 대체 셔틀 운행안 · sol 4회차

11개 노선에 차량을 1대씩 배분한다.

- **R01** 두암빌라 일대 → 온수역 / 1대 / 온수권 밀집 수요를 짧게 연결하고, 하차 후 도보 약 2분인 온수역 정류장을 쓴다.
- **R02** 연세중앙교회 일대 → 오류동역 / 1대 / 온수·오류동 권역 경계의 수요를 모아 오류지구대·텃골에서 철도로 연결한다.
- **R03** 동부골든아파트후문 일대 → 오류동역 / 1대 / 오류동역 북쪽 주거지 수요를 오류1동주민센터 쪽에서 환승시켜 R02와 승차 수요를 나눈다.
- **R04** 용두연립 일대 → 개봉역 / 1대 / 오류동 동쪽과 개봉 서쪽의 수요를 개봉사거리 쪽에서 철도로 연결한다.
- **R05** 경남아파트앞 일대 → 개봉역 / 1대 / 개봉 북쪽과 양천구청 권역 남쪽의 수요를 삼환로즈빌아파트 정류장에서 환승시킨다.
- **R06** 거성슈퍼 일대 → 개봉역 / 1대 / 개봉 남쪽과 광명사거리 권역 경계의 수요를 짧은 왕복으로 처리한다.
- **R07** 고척중학교 일대 → 구일역 / 1대 / 고척동과 구일역 북쪽 수요를 동양미래대학·구로성심병원 정류장에서 환승시킨다.
- **R08** 롯데아파트 일대 → 구로역 / 1대 / 구로역 남쪽의 밀집 수요를 가까운 철도역으로 자주 연결한다.
- **R09** 구로2동지하차도입구 일대 → 남구로역 / 1대 / 남구로권 서쪽과 구일권 남쪽 수요를 구로시장을 통해 철도로 연결한다.
- **R10** 구로구청후문 일대 → 대림역 / 1대 / 구청 주변 수요를 대림역까지 도보 153초인 구로고등학교 정류장에 내린다.
- **R11** JNK디지털타워·구로남초등학교 일대 → 구로디지털단지역 / 1대 / 디지털단지 쪽과 가리봉 방면의 수요를 두 승차점에서 모아 KEB하나은행 정류장에서 환승시킨다.

**두 지표 사이의 선택.** 내부 비교에서 천왕 직결에 2대를 둔 후보는 0~90분 평균 누적 수요충족률이 높았고, 제출안은 구로디지털단지 방면까지 차량을 분산해 90분 내 도착 인원을 우선했다.

**서비스 공백.** 역곡권 816명, 도림천권 183명, 신정네거리권 29명의 출발 정류장은 모두 배정 승차점에서 500m 밖이다. 신도림권은 275명 중 20명분, 천왕권은 1,008명 중 171명분의 출발 수요가 승차점 도보권에 든다. 항동과 천왕 남부까지 노선을 연장하는 데 드는 회차 시간, 신도림·도림천 방면에 별도 차량을 배치할 때 줄어드는 다른 권역의 수송 여력을 고려했다. 철도망 미포함 829명은 전체 수요 16,230명에 포함했다.

**비교에 쓴 가정.** 시간대 안의 출발은 균등하게 배치했고, 승차 전 보행 속도는 1.17m/s로 두었다. 기본 비교에서 셔틀은 직선거리의 1.30배를 시속 21km로 달리며 승차 정차 32초와 종점 회차 115초를 적용했다. 철도는 직선거리의 1.23배를 시속 33km로 환산하고 대기·환승에 650초를 더했다. 하차 후 도보는 access.csv의 시간을 사용했고, 셔틀·철도 소요시간을 바꾼 경우도 비교했다.
