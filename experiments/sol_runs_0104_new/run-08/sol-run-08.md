# sol-run-08 운행안

## 노선별 배분

- R01 두암빌라·수궁동 → 온수역 / 1대 / 짧은 회차로 수궁동 수요를 모으고 1·7호선 진입점을 함께 확보한다.
- R02 오류동삼거리·연세중앙교회 → 오류동역 / 1대 / 오류동 서쪽 두 승차권을 한 회차에 연결한다.
- R03 굴다리·호반써밋개봉아파트 → 오류동역 / 1대 / 개봉1동 서쪽의 밀집 수요를 한 번에 태워 자주 회차한다.
- R04 성화단지·개봉사거리 → 개봉역 / 1대 / 개봉역 북쪽의 두 승차권을 묶어 개봉역에 연결한다.
- R05 개웅어린이공원·개봉 남부 → 개봉역 / 1대 / 개봉 남부와 광명사거리 최인접 권역의 일부 수요를 가까운 철도 접근 정류장으로 보낸다.
- R06 청구·동아한신아파트 → 구일역 / 1대 / 고척동 동쪽의 밀집 수요에 짧은 회차를 확보한다.
- R07 하이츠·영화·우방·한국현대아파트·구일초·구일고 → 구일역 / 1대 / 안양천 동쪽 주거지 두 곳에서 승객을 모아 구일역으로 보낸다.
- R08 대림5차아파트·신도림중학교 → 구로역 / 1대 / 신도림동 북쪽의 두 보행권으로 승차 범위를 넓힌다.
- R09 항아리 정류장 일대 → 구로역 / 1대 / 구로2동 수요를 한 곳에서 태우고 짧게 회차해 대기를 줄인다.
- R10 구로4동우체국·고대구로병원 → 남구로역 / 1대 / 병원과 인근 주거지 수요를 구로시장 하차 정류장에서 7호선에 연결한다.
- R11 JNK디지털타워·구로남초등학교 → 구로디지털단지역 / 1대 / 가리봉동 동편과 산업단지 인근의 두 승차권을 2호선에 연결한다.

## 우선순위와 남는 수요

- **두 지표 사이의 선택** — 신도림동의 두 승차권을 잇는 구로역행을 채택했다. 더 짧은 구로역행 후보는 0~90분 평균 누적 수요충족률에 유리했지만, 이 회차에서는 더 많은 승객의 90분 내 도착을 우선했다.
- **승차권 공백** — 지정 승차 정류장까지의 직선 500m 기준으로 역곡 권역 816명과 온수(2752) 권역 286명 전부, 천왕 권역 1,008명 중 896명, 양천구청 권역 651명 중 531명이 승차권 밖이다. 역곡·양천구청역은 접근표에 직접 연결 정류장이 없고, 항동 및 천왕 남쪽까지 운행을 늘리는 후보는 왕복 시간이 길어 같은 차량의 회차가 줄었다.
- **수용 한계** — 45석이 차면 다음 차를 기다려야 하므로 승차권 안에서도 출근 집중 시 일부 수요가 남는다. 철도망 미확인 829명은 전체 16,230명에 포함했다.

## 비교에 쓴 가정

시간대 안의 출발을 균등하게 분산했다. 승차 전 보행은 직선 500m 한도에서 약 4.2km/h로, 셔틀은 직선거리의 1.3배를 약 21km/h로 달리는 것으로 놓았다. 정차·회차 여유를 더해 배차를 근사했고, 하차 후에는 접근표의 보행 시간을 사용했다. 철도 소요는 역 사이 직선거리와 환승 시간 가정으로 근사해 도로·철도 시간이 달라지는 경우도 비교했다. 이 가정은 후보 비교용이다.
