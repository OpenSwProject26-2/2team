# 구로구 대체 셔틀 운행안 · sol 3회차

11개 노선에 45인승 차량을 1대씩 배분한다. 철도역까지 짧게 왕복해 좌석을 자주 공급하고, 한 정류장으로 모으기 어려운 수요는 두 곳에서 태운다.

## 노선별 배분

- **R01** 거리공원·신도림중학교 → 신도림역 / 1대 / 두 곳에서 승차시켜 서울미래초등학교에서 신도림역(`0234`, `1007`)으로 도보 환승할 수 있게 한다.
- **R02** 구로구청후문 일대 → 대림역 / 1대 / 구청 주변 수요를 모아 구로고등학교에서 대림역까지 도보 153초로 연결한다.
- **R03** 가리봉시장·구로시장 → 남구로역 / 1대 / 두 시장을 들러 남구로와 가산디지털단지 권역 일부를 함께 태운다.
- **R04** 구일 하이츠·구일초·구일고 일대 → 구일역 / 1대 / 구일 주거지의 두 승차 지점을 묶어 구일역까지 연결한다.
- **R05** 서울가든아파트 일대 → 개봉역 / 1대 / 개봉 북동쪽 수요와 구일·양천구청 권역 일부를 한 승차 지점에서 받는다.
- **R06** 성화단지 일대 → 개봉역 / 1대 / 성화단지에서도 바로 출발하게 해 개봉 북쪽 두 승차 지점에 좌석을 따로 공급한다.
- **R07** 개봉한진아파트 일대 → 광명사거리역 / 1대 / 역까지 걸어서 닿기 어려운 개봉 남부 수요를 개명초교에서 도보로 연결한다.
- **R08** 동부골든아파트후문 일대 → 오류동역 / 1대 / 오류동역 북쪽에 모인 수요를 중간 정차 없이 연결한다.
- **R09** 연지타운2단지 일대 → 천왕역 / 1대 / 천왕 주거지에서 천왕역 2번 출구로 연결해 하차 후 보행을 77초로 줄인다.
- **R10** 항동하버라인4단지·푸른수목원 → 온수역 / 1대 / 역곡역이 가장 가깝지만 도보 연계가 어려운 항동 수요를 유한공고·성공회대앞에서 온수역으로 연결한다.
- **R11** 두암빌라 일대 → 온수역 / 1대 / 온수역 북쪽 수요를 짧은 왕복 구간으로 반복 수송한다.

**두 목표 사이의 선택** — 온수역 인근에 단거리 노선을 더 두는 안이 0~90분 평균 누적 수요충족률에 유리했지만, 기본 가정에서 90분 내 도착 인원이 더 많고 역곡 권역까지 연결하는 항동발 R10에 1대를 배정했다.

## 서비스가 부족한 수요와 권역

- 철도망에 포함된 수요 중 4,080명은 출발 정류장 기준으로 이 안의 모든 방문 정류장에서 직선 500m 밖에 있다. 이 가운데 오류동 권역이 895명, 양천구청 권역이 512명, 역곡 권역이 361명이다. 오류동 외곽과 양천구청 방면까지 정차 지점을 늘리면 회차가 길어져 좌석 공급이 줄고, 역곡 권역은 `access.csv`에 역곡역 연계 정류장이 없어 항동 일부를 온수역으로 연결했다.
- 구로디지털단지 권역은 수요 329명 중 200명이 출발 정류장에서 철도역까지 500m 이내다. 이 권역에는 차량을 배정하지 않아 철도망에 포함되면서 철도역도 바로 걸어갈 수 없는 122명의 셔틀 수요가 남는다.
- 방문 정류장 500m 안에도 만차로 20분 내 탑승하기 어려운 수요가 남을 수 있다. 철도망에 포함되지 않은 829명도 전체 수요 16,230명에 포함된다.

## 후보 비교에 사용한 가정

- 출발은 각 시간대 안에 고르게 분포한다고 놓았다. 승차 전 보행은 직선거리의 1.16배와 초당 1.2m를, 하차 후 보행은 `access.csv`의 시간을 적용했다.
- 셔틀은 직선거리의 1.35배를 시속 19km로 이동하고, 정차당 35초와 한 회차당 추가 100초가 걸린다고 가정했다. 차량당 45석을 적용하고 만차 시 20분 한도에서 다음 차를 기다리게 했다. 10분 내 탑승도 함께 비교했다.
- 철도 이동은 역간 직선거리의 1.35배를 시속 32km로 이동하는 근사값에 기본 5분과 노선군이 달라질 때 8분을 더했다. 셔틀과 철도 이동이 모두 더 느린 가정에서는 R10의 90분 내 도착 인원 이점이 사라졌다. 실제 도로 동선과 회차 가능 여부, 철도 운행 및 환승시간은 CSV로 확인할 수 없다.
