# sol-run-05 구로구 대체 셔틀 운행안

- **R01** 고척시장·고척중학교 일대 → 구일역 / 1대 / 청구아파트·동아한신아파트 정류장으로 승차를 모아 동양미래대학 앞까지 짧게 왕복한다.
- **R02** 신도림중학교 일대 → 구로역 / 1대 / 신도림동 주거지에 별도 승차 지점을 두고 구로역까지 짧게 연결한다.
- **R03** 개봉1동사거리·세곡초 일대 → 오류동역 / 1대 / 호반써밋개봉 인근에서 승차를 모아 오류1동주민센터에서 철도로 넘긴다.
- **R04** 수궁동·우신중고 일대 → 온수역 / 1대 / 두암빌라를 거점으로 학교와 주거지 수요를 모으고 하차 후 1·7호선을 선택할 수 있게 한다.
- **R05** 고대구로병원·구로119안전센터 일대 → 남구로역 / 1대 / 병원 정문 인근에서 모아 구로시장에 내려 7호선 도보 환승을 연결한다.
- **R06** 구로구청·구로초 일대 → 구로역 / 1대 / 항아리 정류장에서 구로동 중심부 수요를 받아 신도림중학교 방면과 승차권역을 나눈다.
- **R07** 고척근린시장·개봉사거리 일대 → 개봉역 / 1대 / 성화단지와 경인중학교 두 곳에서 승차를 받아 고척·개봉 북측을 잇는다.
- **R08** 오류동역 정류장·씨티월드 일대 → 오류동역 / 1대 / 두 승차 지점의 수요를 묶어 개봉1동 방면 노선과 나누고, 2번 출구 인근에서 환승 보행을 줄인다.
- **R09** 개봉3동·개봉한진아파트 일대 → 개봉역 / 1대 / 경북슈퍼마켓에서 개봉 남쪽과 광명사거리역 권역 일부의 승차 수요를 받는다.
- **R10** 구로1동 아파트·구일초 일대 → 구일역 / 1대 / 아파트 단지와 학교 앞을 거쳐 고척 방면과 별도로 구로1동을 연결한다.
- **R11** 가산디지털단지·구로남초 일대 → 구로디지털단지역 / 1대 / 디지털단지오거리와 구로남초 주변의 수요를 모아 2호선으로 보낸다.

**두 지표 사이의 선택** — 천왕 연결을 넣은 안이 일부 주행 조건에서 0~90분 평균 누적 수요충족률에 유리했지만, 여러 주행 조건을 종합해 90분 내 도착 인원이 더 많았던 구로디지털단지 연결을 선택했다.

## 서비스가 부족한 수요와 권역

- 승차용으로 잡은 정류장까지 직선 500m를 넘는 철도망 포함 수요는 3,854명이다. 출발 정류장에서 가장 가까운 역으로 권역을 나누면, 천왕은 철도망 포함 933명 중 76명, 양천구청은 633명 중 119명이 승차 도보권에 든다. 역곡 742명과 온수 7호선 권역 264명은 승차 도보권 밖이다.
- 양천구청역과 역곡역은 CSV에 도보 환승이 가능한 하차 정류장이 없어 인접 역으로 연결해야 한다. 천왕과 항동 안쪽까지 운행할 차량은 수요가 모여 있고 짧게 회차할 수 있는 구간에 배분했다. 07시대에는 승차 도보권 안에서도 45석이 차면 다음 차를 기다리는 수요가 생길 수 있다.
- 철도망 미포함 수요 829명은 전체 16,230명에 포함된다.

## 비교에 사용한 가정

출발은 각 시간대 안에서 고르게 분포한다고 가정했다. 승차 보행은 직선거리 1m당 0.92초, 하차 후 보행은 access.csv의 시간을 적용했다. 셔틀은 직선거리 1km당 약 3.6~5.5분, 정류장 정차 22~32초, 회차 여유 60~95초를 적용해 비교했다. 철도 이동은 역 번호와 좌표, 역명을 바탕으로 연결을 추정하고 첫 열차 대기와 환승 시간을 더했다.
