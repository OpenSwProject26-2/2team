# 독립형 시민 길찾기

운영자 대시보드와 기존 시민 미리보기와 별도로 실행하는 시민용 길찾기입니다. A팀 GTFS와 OSM을 사용해 일반 OTP 그래프를 만들고, 정확한 파업 `route_id`를 제외한 별도 파업 그래프를 만듭니다. C팀 M05 시간표와 M07 결과가 있으면 셔틀을 파업 그래프에 추가할 수 있습니다. OTP 2.10.0이 경로를 계산하고 시민 API가 결과를 표시합니다.

## 문서

- [필요 데이터·출처·공유 범위](docs/data-requirements.md): 팀원이 별도로 준비할 파일, 로컬 집계 자료와 OTP 입력의 차이, 데모의 한계
- [일반·파업 모드 준비와 실행](docs/strike-mode-integration.md): GTFS 내보내기, 두 그래프 빌드, 세 서버 실행, 검증
- [화면·API·지도 설명](docs/setup.md): 장소 선택, 추천 경로, 일반 시설 POI, API와 오류

## 현재 구현

- 장소 이름 검색과 지도 클릭·좌표 선택, 경로 카드 및 지도 표시
- 일반/파업 모드 자동 재검색과 동일 OD 비교, 최적·최소 시간·최소 환승·최소 도보 정렬
- 시민 전용 MapLibre/OpenFreeMap 스타일의 단계적 일반 시설 POI 표시
- 지도 배경 타일·글꼴·스프라이트는 인터넷 연결이 필요하고, 장소 이름 색인은 로컬 OSM PBF에서 생성
- 일반 OTP: `127.0.0.1:8080`, 파업 OTP: `127.0.0.1:8081`, 시민 화면/API: [`127.0.0.1:8775`](http://127.0.0.1:8775/)

현재 로컬의 구로 `plan-smoke@1` 셔틀은 **스모크 데모이며 실제 운행안이 아닙니다**. 로컬 `runtime/`의 그래프와 원자료는 저장소에 포함되지 않습니다. 새 clone에서 실제 검색을 하려면 [필요 데이터](docs/data-requirements.md)를 별도로 준비해야 합니다. 저장소의 fixture만으로 단위 테스트는 실행할 수 있습니다.

커밋 전에 `py -3 -B -m unittest discover -s tests -v`와 `git diff --check`로 확인하세요. 원자료·ZIP·OTP 그래프·인증키는 Git에 넣지 않습니다.
